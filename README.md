# Online Shopping Management System

## 📌 Project Overview

The **Online Shopping Management System** is a Database Management System (DBMS) project developed to manage the operations of an online shopping platform.

The system uses a relational database to manage users, products, categories, suppliers, inventory, carts, orders, payments, shipments, reviews, and other related information.

## 🛠️ Technologies Used

- **MySQL** – Relational Database Management System
- **phpMyAdmin** – Database management and testing
- **XAMPP** – Local development environment

## 🗄️ Database

The project contains **16 relational tables**:

1. users
2. products
3. categories
4. suppliers
5. inventory
6. carts
7. cart_items
8. wishlists
9. wishlist_items
10. orders
11. order_items
12. coupons
13. addresses
14. payments
15. shipments
16. reviews

The database includes relationships between users, products, categories, orders, payments, shipments, reviews, and other entities.

💾 How to Run the Database
Install XAMPP.
Start Apache and MySQL from the XAMPP Control Panel.
Open phpMyAdmin.
Create/import the database using the SQL file:
sql/Project.sql
Execute the SQL file to create the tables and database structure.
Verify the tables and data in phpMyAdmin.
